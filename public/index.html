About this class

코드를 외우는 대신,
원하는 걸 말로 설명하는 법을 배워요

바이브 코딩은 문법 대신 대화로 만드는 방식이에요. 나는 방향을 잡고 결과를 확인하고, 코드는 AI가 씁니다.

바이브 코딩은 키오스크와 같아요.

처음 보는 키오스크는 어렵게 느껴지지만, 알고 보면 몇 가지 간단한 기능의 조합이에요. 바이브 코딩도 익숙하지 않을 뿐, 알고 나면 별것 아니에요. 이 수업은 그 시작을 편하게 만드는 방법을 알려 드리고, 실제 결과물까지 함께 만들어 냅니다. 결과물은 홈페이지가 될 수도, 업무 자동화가 될 수도 있어요. 이번 수업은 홈페이지로 진행합니다.

  1. 말로 설명하기"예약 버튼이 있는 우리 카페 홈페이지 만들어줘"처럼 평소 쓰는 말로 시작해요.
  2. AI가 바로 만들기Claude Code가 파일을 만들고 코드를 작성하고, 실행까지 해서 결과를 보여 줘요.
  3. 보고 고치기"버튼을 더 크게", "색을 따뜻하게". 마음에 들 때까지 대화로 다듬어요.
💻

터미널을 사용하지 않아요검은 화면에 명령어를 입력할 필요가 없어요. 모든 실습은 클로드 브라우저(claude.ai) 또는 Claude 데스크탑 앱에서 대화하듯 진행합니다.

이런 분께 추천해요

  • 내 가게·브랜드 홈페이지를 직접 만들고 싶은 사장님
  • 외주 없이 회사·팀 소개 홈페이지를 빠르게 만들고 싶은 창업자·직장인
  • 포트폴리오나 개인 브랜드 홈페이지가 필요한 프리랜서·크리에이터
  • AI 코딩 도구가 궁금했지만 혼자 시작하기 막막했던 분
  • 코딩 공부를 시도했다가 문법에서 포기한 경험이 있는 분
  • 요즘 말하는 '바이브 코딩'을 직접 체험해 보고 싶은 분

Curriculum

커리큘럼

설명은 짧게, 실습은 길게. 3시간 동안 홈페이지를 만들어 공개하고, 손님을 받는 서비스로 키워요.

3시간 과정

홈페이지 제작·배포부터 도메인·알림·문자 인증까지

  • 7차시 · 3시간
  • 55,000원
  • 모집 중
  1. 01차시

    바이브 코딩, 편하게 시작하기

    키오스크처럼 몇 가지 기본 동작만 익히면 돼요. Claude에게 원하는 것을 설명하고, 결과를 보고, 다시 요청하는 흐름을 손에 익혀요.

    • Claude
    • 프롬프트 작성법
  2. 02차시

    내 홈페이지 만들기

    가게·회사 소개, 포트폴리오, 개인 브랜드 중 하나를 골라 대화만으로 홈페이지를 완성해요. 신청·문의를 관리하는 어드민(관리자) 화면도 함께 만들어요.

    • 홈페이지
    • 어드민 화면
  3. 03차시

    누구나 볼 수 있게 배포하기

    만든 홈페이지를 깃허브에 올리고 Railway로 배포해, 친구에게 보낼 수 있는 실제 인터넷 주소를 받아요.

    • GitHub
    • Railway
  4. 04차시

    어드민 보안: 서버 환경변수 설정

    관리자 비밀번호 같은 중요한 정보를 코드에 적지 않고 서버 환경변수로 안전하게 보관하는 방법을, 왜 그래야 하는지와 함께 설명해요.

    • 환경변수
    • 관리자 보안
  5. 05차시

    도메인 연결

    정리된 서비스 이름의 도메인을 연결해, 기억하기 쉬운 나만의 주소로 외부에 공개해요.

    • 도메인
    • DNS
  6. 06차시

    텔레그램 API로 유입 정보 받기

    홈페이지로 들어온 신청·문의 정보를 텔레그램으로 바로 받아 볼 수 있게 연결해요.

    • Telegram API
    • 실시간 알림
  7. 07차시

    문자 API로 유효한 고객 확보

    휴대폰 문자 인증을 붙여 실제로 연락 가능한, 유효한 고객 정보만 받는 방법을 배워요.

    • SMS API
    • 휴대폰 인증

수업이 끝나면 인터넷에 공개된 내 홈페이지와 안전한 관리자 화면, 그리고 손님을 받고 검증까지 해 주는 나만의 서비스를 가져가요.

FAQ

자주 묻는 질문

더 궁금한 점은 bill@neonex.team로 편하게 물어보세요.

코딩을 정말 하나도 몰라도 되나요?

네. 이 클래스는 코딩 경험이 전혀 없는 분을 기준으로 만들었습니다. 코드를 직접 쓰는 대신 원하는 것을 말로 설명하는 방법을 배웁니다.

Claude 유료 구독이 필요한가요?

네. Claude Code를 쓰려면 Claude Pro 이상 유료 요금제가 필요해요. 수업 전에 claude.ai에서 Pro 결제를 마치고 오시면 바로 실습을 시작할 수 있어요.

수강료는 언제 어떻게 내나요?

미리 결제하실 필요 없어요. 수업 당일 현장에서 수강료(3시간 과정 55,000원, 11/21·11/22·11/29 기본 과정 30,000원)를 결제해 주시면 됩니다.

노트북 사양이 낮아도 괜찮나요?

괜찮습니다. 무거운 작업은 AI 쪽에서 처리하기 때문에 인터넷과 웹 브라우저가 잘 되는 노트북이면 충분합니다.

수업이 끝나면 무엇을 가져가나요?

직접 만든 홈페이지와 그 홈페이지에 접속할 수 있는 실제 주소, 그리고 혼자서도 계속 만들어 갈 수 있는 작업 흐름을 가져가십니다.
