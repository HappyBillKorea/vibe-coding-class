# 바이브 코딩 입문 클래스

Claude Code로 배우는 바이브 코딩 입문 오프라인 클래스(2시간) 홍보 페이지와 수강 신청 서버입니다.

- 일정별 남은 자리 표시, 회차당 최대 6명
- 신청 시 휴대폰 문자 인증 (솔라피), 신청 완료 확인 문자 발송
- `/admin.html` 에서 신청자 명단 확인·취소

## 채워 넣을 것
- `public/index.html` 에서 노란색으로 표시된 `[...]` 부분: 수강료, 장소, 강사 정보, 환불 규정, 문의처
- 후기 섹션의 예시 후기 3개를 실제 수강생 후기로 교체 (교체 후 `sample` 클래스와 "예시 후기" 표시 삭제)
- `schedule.json` 의 일정과 장소 (예시 일정이 들어 있어요). `capacity` 를 빼면 6명입니다. 이미 신청자가 있는 일정의 `id` 는 바꾸지 마세요.

## 환경 변수 (Railway → Variables)
| 이름 | 설명 |
| --- | --- |
| `SOLAPI_API_KEY` | 솔라피 API 키 |
| `SOLAPI_API_SECRET` | 솔라피 API 시크릿 |
| `SOLAPI_SENDER` | 솔라피에 등록된 발신번호 |
| `ADMIN_KEY` | 신청자 명단 페이지 비밀번호 |
| `DATA_DIR` | 신청 데이터 저장 경로. Railway 볼륨을 `/data` 에 붙이고 `/data` 로 지정 |

볼륨 없이 배포하면 재배포할 때마다 신청 데이터가 사라집니다.

## 로컬 실행
```
npm install
npm start
```
솔라피 키 없이 실행하면 문자 대신 화면과 콘솔에 인증번호가 표시되는 개발 모드로 동작합니다.
